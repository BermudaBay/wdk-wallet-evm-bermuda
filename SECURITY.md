# Security Policy

## Scope

This policy covers this repository and the `@bermuda/wdk-wallet-evm-bermuda` package built from it. If you are not
sure whether an issue belongs here, in the Bermuda SDK (`@bermuda/sdk`) or in an upstream WDK package, report it to us
anyway and we will route it.

## Supported Versions

Security fixes are released for the latest version only. The package is in beta, so please check that the issue
still exists in the latest version before reporting it.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions or pull requests.**

Email [security@bermudabay.xyz](mailto:security@bermudabay.xyz) instead, with a subject starting with `[SECURITY]`.
Include as much of the following as you can:

- the affected version or commit;
- a description of the vulnerability and its impact;
- the steps to reproduce it, or a proof of concept;
- the network, tokens and configuration involved, if relevant.

Never send seed phrases, private keys or funds. Use Plasma testnet and throwaway keys, and redact your logs.

## Disclosure

We will confirm that we received your report, keep you informed while we investigate and fix the issue, and coordinate
its public disclosure with you once a fixed version is available. Please keep the issue confidential until then. With
your consent, we will credit you for the report.
